# Wasim Ansari — Portfolio Website

A modern, production-ready personal portfolio built with React.js + Vite.

## 🚀 Tech Stack
- React.js + Vite
- Tailwind CSS v4
- Framer Motion
- React Icons

## 📁 Folder Structure
```
src/
├── assets/
├── components/
│   ├── common/     # SectionWrapper, ScrollToTop
│   └── layout/     # Navbar, Footer
├── context/        # ThemeContext (dark/light)
├── data/           # portfolioData.js
├── hooks/          # useTypingEffect, useScroll
└── pages/          # All sections
```

## 🛠️ Setup
```bash
npm install
npm run dev
```

## 🔧 Customization
Edit `src/data/portfolioData.js` to update all content.

## 📦 Build
```bash
npm run build
```
